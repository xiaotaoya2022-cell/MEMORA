# 品牌资产

本目录的图形来自项目所有者提供的品牌稿件，作为既定身份使用，不再另行生成或重绘。

| 文件 | 尺寸 | 用途 |
|---|---|---|
| `icon.png` | 268 × 268，透明圆角 | 应用图标、README 标识、托盘图标来源 |
| `cover.png` | 1186 × 1220，透明圆角 | 品牌卡片，用于仓库首页、社交预览图 |

约束：

- `icon.png` 为位图，原稿即此分辨率；如需矢量版本或多尺寸 `.ico`，应从本文件导出，不重新创作图形。
- 图标在 16–32 px 下会损失细线细节，小尺寸使用前需实测。
- 品牌色：智能核心紫 `#A99AFF`，科技蓝 `#65D9FF`，深空底 `#111827`。
