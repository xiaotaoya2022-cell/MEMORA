# 品牌资产

本目录的图形为项目既定身份，来自项目所有者提供的稿件，不再另行生成或重绘。

| 文件 | 尺寸 | 格式 | 用途 |
|---|---|---|---|
| `cover.jpg` | 1536 × 1024 | JPEG，满版无透明 | 品牌封面：深空底、紫蓝渐变缎带 M、环轨光点、字标与 slogan。用于仓库首页、社交预览图 |
| `icon.png` | 1254 × 1254 | PNG，圆角透明（半径 240） | 应用图标：白色底板 + 石墨色立体缎带 M，单色版本 |

约束：

- 两者为同一套缎带造型的两个版本：封面是彩色（紫 → 蓝），图标是石墨色单色。跨场景并置时注意这一差异。
- `icon.png` 为位图。打包 `.ico` 时从本文件按 256 / 128 / 64 / 48 / 32 / 16 逐级导出；16–32 px 下缎带的明暗转折会糊成一片，必要时改用封面里的细线版本或做小尺寸专用简化，实测后再定。
- 品牌色：智能核心紫 `#A99AFF`，科技蓝 `#65D9FF`，深空底 `#111827`。
- 图标底板为白色，在浅色背景上会与背景融合，只剩缎带可见；这不是缺图。
